Python API and Automation Project

About

This project contains beginner-friendly Python programs that demonstrate API integration and AI application development.

Features

* REST API requests using Python
* Weather information using a public API
* JSON data retrieval
* AI Study Assistant using Groq
* Environment variable management for API keys

Technologies Used

* Python
* REST APIs
* JSON
* Streamlit
* Groq API

Setup Instructions

1. Clone or download this repository.
2. Create and activate a virtual environment.
3. Install the required Python packages.
4. Create a .env file in the project folder and add your Groq API key:
    GROQ_API_KEY=your_groq_api_key
5. Run the Python program you want to use.

Security

Never upload your .env file or API keys to GitHub.
